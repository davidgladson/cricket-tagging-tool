# Cricket Tagging Tool
Repository for maintaining all code for Cricket Tagging Tool

## How To Set Up
Run the following steps: <br>
```
cd {yourpath}/cricket-tagging-tool
pip install -r requirements.txt 
```

## How to Run
To run locally, after following the set-up instructions above, use following commands <br>
```
cd {yourpath}/cricket-tagging-tool
streamlit run home_page.py
```
